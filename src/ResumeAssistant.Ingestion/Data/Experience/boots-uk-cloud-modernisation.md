# Azure Cloud Modernisation for 25,000+ Enterprise Users

Served as the Lead Azure Solution Architect for a strategic cloud modernisation programme at a Major UK Health & Beauty Retailer, responsible for the end-to-end technical design and cloud migration of **7 business-critical applications supporting over 25,000 internal users**.

## 1. Enterprise Cloud Migration & Solution Architecture
- Designed scalable Azure-native target architectures utilizing **Azure App Services**, **Azure API Management (APIM)**, **Azure Key Vault**, **Azure SQL**, and **Azure Storage**.
- Implemented robust API Management policies for rate limiting, JWT token validation, response caching, and mutual TLS to secure corporate enterprise backends.
- Formulated Cloud FinOps cost-optimization strategies, sizing cloud compute resources and utilizing auto-scaling rules that reduced operational spend by over 25%.

## 2. Reusable Stub Identity Platform
- Designed and built a high-performance **Stub Identity Platform** to simulate production OAuth2/OIDC identity providers under heavy concurrent load.
- Unblocked enterprise-scale performance and load testing across multiple development streams without impacting production authentication services or incurring third-party API licensing costs.

## 3. Cloud Governance & Multi-Team Enablement
- Partnered directly with Microsoft FastTrack engineers and client executive leadership to govern migration strategies across a portfolio of approximately 90 enterprise services.
- Created standardized Infrastructure as Code (IaC) templates, Azure DevOps CI/CD pipelines, and cloud security baselines adopted by multiple delivery teams.
