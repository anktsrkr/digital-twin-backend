# Azure Cloud Modernisation for 25,000+ Internal Users

Led Azure architecture and cloud modernisation for **7 business-critical applications supporting over 25,000 internal users** at a major UK health & beauty retailer.

## Key Contributions & Architectural Achievements
- Designed Azure-native solutions using Azure App Services, API Management (APIM), Key Vault, Azure Storage, and Azure DevOps, with a strong focus on resilience, security, and cost-aware FinOps architecture.
- Designed and delivered a reusable **Stub Identity Platform** that removed a critical programme dependency and enabled enterprise-scale performance testing without impacting production identity services.
- Developed reusable frameworks, shared platform services, and engineering accelerators adopted across multiple delivery teams.
- Partnered with Microsoft architects and client engineering leadership to establish cloud governance and migration strategy across a programme modernising approximately 90 enterprise applications.
