# Large-Scale National Railway Azure Migration Programme

Supported a major enterprise cloud migration programme for a National European Railway Operator, modernising mission-critical rail transportation workloads and legacy enterprise application estates to Microsoft Azure.

## 1. Cloud Adoption Framework & Migration Strategy
- Formulated cloud adoption blueprints, Azure Landing Zone architectures, and migration pathways adhering to the **Microsoft Cloud Adoption Framework (CAF)**.
- Assessed legacy on-premise monolithic applications, categorizing workloads into the 6 Rs of cloud migration (Rehost, Replatform, Refactor, Repurchase, Retire, Retain).
- Established strict security, compliance, and governance guardrails aligned with European Union regulatory standards and GDPR.

## 2. Workload Discovery & Dependency Analysis
- Led deep-dive technical discovery sessions with distributed infrastructure and application teams to map complex multi-tier dependencies, database coupling, and network topographies.
- Designed phased cutover strategies to minimize rail operations disruption and ensure business continuity during zero-downtime database and application migrations.
- Established landing zone networking topologies including Hub-and-Spoke virtual networks, Azure ExpressRoute integration, and firewall perimeter routing.
