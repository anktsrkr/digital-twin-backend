# Large-Scale National Railway Azure Migration Programme

Supported a large-scale Azure migration programme for Belgium's national railway operator (SNCB/NMBS), covering complex enterprise applications and mission-critical transportation infrastructure.

## Key Responsibilities & Highlights
- Defined migration strategies, Azure Landing Zone architecture, and cloud adoption roadmaps aligned with business objectives and strict European regulatory compliance.
- Contributed to governance, workload discovery, dependency analysis, and migration planning across multiple distributed delivery teams.
- Assessed legacy monolithic applications and mapped rehosting, refactoring, and re-platforming migration pathways to Azure.
