# Core Technical Skills & Architectural Competencies

A comprehensive competency matrix detailing technical mastery and architectural depth across 5 core engineering pillars, honed over 13+ years of architecting, delivering, and scaling mission-critical enterprise platforms and AI systems:

## 1. Engineering Leadership & Governance
- **Technical Leadership:** Technical Ownership, Practice Leadership, Architecture Review Boards (ARB), Engineering Standards & RFCs, Team Mentorship & Enablement.
- **AI-Assisted Delivery:** Microsoft Agent Framework (`Microsoft.Agents.AI`), GitHub Copilot Agents, Reusable Agent Skills, Prompt Engineering, Zero-Trust Agent Identities, Content Moderation & Guardrails.
- **Culture & Methodologies:** InnerSource Practices, Agile/Scrum, Domain-Driven Design (DDD), Event Storming.

## 2. Enterprise & Platform Architecture
- **Distributed Architecture:** Event-Driven Architecture (EDA), Asynchronous Messaging, Microservices, Clean Architecture, CQRS, Event Sourcing, High-Concurrency Order Orchestration.
- **Enterprise Integration:** API Management (APIM), Azure Integration Services (Service Bus, Event Grid, Event Hubs), RESTful APIs, Webhooks, Model Context Protocol (MCP).
- **Cloud Governance:** Azure Landing Zones, Microsoft Cloud Adoption Framework (CAF), Azure Policy, Multi-Tenant Partitioning, Zero-Trust Security.

## 3. Platform Engineering & DevSecOps
- **Infrastructure as Code (IaC):** Reusable Terraform Modules (`terramodules`), Terraform Cloud, Remote State with Azure AD Auth, Bicep, ARM Templates.
- **CI/CD & Release Automation:** Release Please (Automated SemVer & Conventional Commits), Azure DevOps Pipelines, GitHub Actions, Docker, Containerization.
- **Developer Experience (DevEx) & IDP:** Internal Developer Platforms (IDP), Internal NuGet Package Ecosystem (Azure Artifacts), Project Scaffolding CLI, Golden Paths, Pre-Commit Hooks.
- **Security & Compliance:** GitHub Advanced Security (CodeQL, Secret Scanning, Dependabot), SAST/DAST, OAuth2/OIDC, Key Vault Secret Management, Smart DLP.

## 4. SRE, Observability & Cloud FinOps
- **Enterprise Observability:** OpenTelemetry (OTel), Azure Monitor, Application Insights, Log Analytics, Grafana LGTM (Tempo, Loki, Mimir), W3C Distributed Tracing.
- **Resilience Engineering:** Site Reliability Engineering (SRE), Chaos Engineering, Idempotent Consumers, Circuit Breakers (Polly), Dead Letter Queue (DLQ) Auto-Replay.
- **Cloud FinOps:** Cloud Resource Right-Sizing, Auto-Scaling Strategies, Cost Allocation Tags, Multi-Account Free Tier Pooling (Zuplo AI Gateway).

## 5. Technology Stack & Frameworks
- **Cloud & Databases:** Microsoft Azure (Expert), MongoDB / MongoDB Atlas Vector Search, Azure Cosmos DB, Azure Cache for Redis, SQL Server, AWS (Cloud Practitioner).
- **Backend & Languages:** C#, .NET 10 / .NET 9 / .NET 8, ASP.NET Core, Entity Framework Core, TypeScript, Node.js, Python (AI tooling).
- **AI & Integrations:** Microsoft Agent Framework (`Microsoft.Agents.AI`), `Microsoft.Extensions.AI`, Jina AI Embeddings, Cloudflare Workers AI, Cal.com API v2, Clerk Identity, Zuplo API Gateway.
