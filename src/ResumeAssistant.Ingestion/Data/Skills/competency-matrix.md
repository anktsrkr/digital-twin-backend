# Core Technical Skills & Architectural Competencies

Deep technical mastery across 5 primary engineering pillars:

## 1. Engineering Leadership & Governance
- **Areas:** Technical Ownership, Architecture Governance, Cross-Functional Leadership, Engineering Standards, Mentoring & Technical Enablement.
- **AI Delivery:** Agentic AI, AI-Assisted Software Delivery, Prompt Engineering & Guardrails.

## 2. Enterprise & Platform Architecture
- **Areas:** Platform Strategy, Solution & System Design, Distributed Systems, Event-Driven Architecture (EDA), Microservices, Domain-Driven Design (DDD).
- **Integration:** API Management & Design, Azure Landing Zones & Governance, Zero-Trust Architecture.

## 3. Platform Engineering & DevSecOps
- **Infrastructure as Code:** Terraform, Bicep, Azure Resource Manager (ARM).
- **CI/CD & Automation:** GitHub Actions, Azure DevOps Pipelines, InnerSource Practices, Docker & Containerization.
- **Developer Experience:** Internal Developer Platforms (IDP), DevEx Accelerators, NuGet Package Management.

## 4. SRE, Observability & Cloud FinOps
- **Observability:** Azure Monitor, Application Insights, Log Analytics, OpenTelemetry, Distributed Tracing (W3C).
- **Resilience:** Site Reliability Engineering (SRE), Chaos Engineering, Disaster Recovery, High-Availability Systems.
- **FinOps:** Cloud FinOps, Azure Cost Management, Resource Right-Sizing.

## 5. Technology Stack & Frameworks
- **Cloud:** Microsoft Azure, AWS (Fundamentals).
- **Backend & Languages:** C#, .NET 8 / 9 / 10, ASP.NET Core, Entity Framework Core, SQL Server, Cosmos DB, Redis.
- **Messaging & Eventing:** Azure Service Bus, Event Grid, Event Hubs, Azure Functions (Isolated Worker), Durable Task Framework.
